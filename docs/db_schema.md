# Database Schema Snapshot

## `Info.mdb`
- `DC`: interlocking device wiring / adjacency map
- `QD`: track section definitions
- `XH`: signal definitions
- `StationInfo`: station labels
- `YHInfo`: yard / screen mapping

## `Data.mdb`
- `Route`: route definitions
- `Condition`: route conditions
- `Reserved`: reserved route metadata

## `Signal.mdb`
- `FZDelay`: closure/open-delay settings
- `JWDSignal`: directional signal list
- `PassSignal`: through-route signal mapping
- `TFSignal`: special signal list
- `YDDelay`: guide-route delay settings
- `YDSignal`: guide signal list

## `System.mdb`
- `System`: workstation/network config
- `本机设置`: local station config

## `passwdcheck.mdb`
- `check`: password operation log

## `Assistant.mdb`
- `AutoBSFZ`
- `CZtoCZFZ`
- `HandBSFZ`

- `CXJY`
- `JK`
